# Infosys Specialist Programmer (SP) - 20 Interactive Practice Sets

Welcome to your offline Notepad Practice Arena! This directory contains 20 full exam sets (80 coding problems) matching the official Infosys in-person assessment format.

---

## How to Practice in Notepad (Exact Exam Simulation)

1. Open the Problem in Notepad:
   notepad Set_01\Q1_Easy.java

2. Read the Problem at the Top:
   Every file starts with a multi-line Java docstring containing:
   - Problem Description & Corporate Story
   - Constraints & Target Hardware Complexity
   - Sample Inputs and Expected Outputs
   - The Infosys Trap Alert (32-bit overflow, TLE traps, edge cases)

3. Write Your Logic in the Empty Method:
   Scroll to '// TODO: IMPLEMENT YOUR OPTIMAL LOGIC IN THIS METHOD'. Write your code directly inside the method body.

4. Compile and Test:
   javac Set_01\Q1_Easy.java
   java -cp Set_01 Q1_Easy

5. Inspect the Reference Solution (If Stuck):
   If you get stuck, a fully verified reference optimal solution is cleanly commented at the bottom of the file!
