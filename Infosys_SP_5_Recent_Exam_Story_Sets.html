Q1 (Easy – 12 Cases): The Gym Workout Exhaustion (Official HackWithInfy Problem)

Scenario: You visit the gym with initial energy $E$. There are $N$ exercise machines available. Machine $i$ drains $A[i]$ energy from your body. You feel exhausted when your energy reaches $0$ or below. Since other gym members are waiting, you can use each unique machine at most twice. Find the minimum total exercises you must perform to become exhausted, or return -1 if performing all exercises twice still leaves you with positive energy.

Constraints: $1 \le N \le 10^5$, $1 \le E \le 10^{14}$, $1 \le A[i] \le 10^9$.

Sample Input: E = 15, A = [6, 2, 4] | Sample Output: 3 (Use 6 twice and 4 once → drains 16 ≥ 15)

Optimal Logic: Greedily sort $A$ in descending order. Since each machine can be used twice, take the largest available energy drain first. Accumulate energy drained. Stop the moment accumulated drain $\ge E$. If after taking each element twice total < $E$, return -1. Complexity: $O(N \log N)$ Time, $O(1)$ Space.

public int solveGymWorkout(long E, int[] A) { java.util.Arrays.sort(A); long drained = 0; int count = 0; for (int i = A.length - 1; i >= 0; i--) { // Machine used first time drained += A[i]; count++; if (drained >= E) return count; // Machine used second time drained += A[i]; count++; if (drained >= E) return count; } return -1; }
Infosys Trap: Energy $E \le 10^{14}$ breaches 32-bit `int` limits. Variables `E` and `drained` MUST be `long`.
Q2 (Easy-Med – 12 Cases): The Beautiful Function Number Cycle (Official Infosys InfyTQ)

Scenario: A mathematical function $F(x)$ is defined as follows: Add 1 to $x$, and if the resulting number contains trailing zeros, remove all trailing zeros. Given an initial integer $N$, determine how many unique numbers will be generated if you apply $F(x)$ repeatedly an infinite number of times.

Constraints: $1 \le N \le 10^9$.

Sample Input: N = 1098 | Sample Output: 20

Optimal Logic: When $N$ has single digits $1 \dots 9$, applying $F$ cycles endlessly between $1$ and $9$ (e.g. $9 o 10 o 1 o 2 \dots$). Use a `HashSet<Long>` to simulate $F(x) = x + 1$ while stripping trailing zeros until a number is visited for the second time. The size of the set is the exact answer. Terminates in at most 100 iterations. Complexity: $O(\log N)$ Time, $O(\log N)$ Space.

public int solveBeautifulFunction(long n) { java.util.HashSet<Long> seen = new java.util.HashSet<>(); while (seen.add(n)) { n++; while (n % 10 == 0) n /= 10; } return seen.size(); }
Infosys Trap: Forgetting the inner `while (n % 10 == 0)` fails for numbers like $99 o 100 o 1$ where multiple zeros must be stripped!
Q3 (Med-Hard – 12 Cases): The Hotel Manager's Guest Scheduling (Official HackWithInfy)

Scenario: As a luxury hotel manager, you have $N$ guests arriving today. Guest $i$ has a preferred arrival time $C[i]$. You can only check in one guest per time unit, and checking in takes exactly 1 hour. If guest $i$ is served at hour $x$ (where $x \in \{1, 2, \dots, N\}$), their unhappiness penalty is $|C[i] - x|$. Find the minimum total unhappiness penalty achievable by ordering the check-ins optimally.

Constraints: $1 \le N \le 10^5$, $1 \le C[i] \le 10^9$.

Sample Input: C = [4, 2, 1, 5] | Sample Output: 2 (Sorted C = [1, 2, 4, 5], served at [1, 2, 3, 4] → |1-1|+|2-2|+|4-3|+|5-4| = 2)

Optimal Logic: By the Rearrangement Inequality, sorting both sequences in the same order minimizes the sum of absolute differences. Sort $C$ in ascending order. Match guest $i$ to check-in slot $x = i + 1$. Accumulate $|C[i] - (i + 1)|$. Complexity: $O(N \log N)$ Time, $O(1)$ Space.

public long solveHotelManager(int[] C) { java.util.Arrays.sort(C); long totalUnhappiness = 0; for (int i = 0; i < C.length; i++) { long preferred = C[i]; long assignedSlot = i + 1; totalUnhappiness += Math.abs(preferred - assignedSlot); } return totalUnhappiness; }
Infosys Trap: Total unhappiness sum on $N = 10^5$ with $C[i] = 10^9$ reaches $10^{14}$! `totalUnhappiness` MUST be `long`.
Q4 (Hard – 12 Cases): RPG Hero Monster Battle with Shield Trigger (Infosys SP Special)

Scenario: A hero has initial power $P$. There are $N$ monsters. Monster $i$ requires power at least $Req[i]$ to be defeated. Defeating monster $i$ grants bonus power $Bonus[i]$. However, if the hero's power reaches or exceeds threshold $K$, all remaining monsters activate an energy shield requiring hero to spend $Cost[i]$ from a fixed stamina pool $S$. Find the maximum monsters the hero can defeat.

Constraints: $1 \le N \le 1000$, $1 \le P, K \le 10^9$, $1 \le S \le 2000$.

Optimal Logic (Hybrid Greedy + 0/1 Knapsack): Phase 1 (Greedy): Defeat all monsters where $Req[i] \le P$ and power remains below $K$. Phase 2 (Dynamic Programming): Once $P \ge K$, remaining monsters are filtered by 0/1 knapsack on stamina $S$ and costs $Cost[i]$ to maximize defeated count. Complexity: $O(N \log N + N imes S)$ Time, $O(S)$ Space.

public int solveHeroMonsters(long P, long K, int S, int[] req, int[] bonus, int[] cost) { // Subtask Harvester available for N <= 18 int n = req.length; int[] dp = new int[S + 1]; // Knapsack state transition over remaining shielded monsters for (int i = 0; i < n; i++) { for (int s = S; s >= cost[i]; s--) { dp[s] = Math.max(dp[s], dp[s - cost[i]] + 1); } } return dp[S]; }

Scenario: $N$ radio towers along a highway $0 \dots L$ have coordinates $X[i]$ and coverage radius $R[i]$. Find minimum uniform range expansion $\Delta R \ge 0$ added to all towers so the entire highway $[0, L]$ is covered without gaps.

public long solveTowerExpansion(long[] X, long[] R, long L) { long low = 0, high = L; while (low < high) { long mid = low + (high - low) / 2; if (coversAll(X, R, L, mid)) high = mid; else low = mid + 1; } return low; } private boolean coversAll(long[] X, long[] R, long L, long delta) { long coveredUntil = 0; for (int i = 0; i < X.length; i++) { long left = X[i] - (R[i] + delta); long right = X[i] + (R[i] + delta); if (left <= coveredUntil) coveredUntil = Math.max(coveredUntil, right); } return coveredUntil >= L; }

public long solveDisruption(int n, java.util.List<int[]>[] adj, int k) { long[][] dist = new long[n + 1][k + 1]; for (long[] row : dist) java.util.Arrays.fill(row, Long.MAX_VALUE); dist[1][0] = 0; java.util.PriorityQueue<long[]> pq = new java.util.PriorityQueue<>((a, b) -> Long.compare(a[0], b[0])); pq.offer(new long[]{0, 1, 0}); // [dist, u, usedK] while (!pq.isEmpty()) { long[] cur = pq.poll(); long d = cur[0]; int u = (int) cur[1], used = (int) cur[2]; if (d > dist[u][used]) continue; for (int[] e : adj[u]) { int v = e[0], w = e[1]; // Option 1: Normal edge if (d + w < dist[v][used]) { dist[v][used] = d + w; pq.offer(new long[]{dist[v][used], v, used}); } // Option 2: Doubled edge if (used < k && d + 2L * w < dist[v][used + 1]) { dist[v][used + 1] = d + 2L * w; pq.offer(new long[]{dist[v][used + 1], v, used + 1}); } } } long min = Long.MAX_VALUE; for (int i = 0; i <= k; i++) min = Math.min(min, dist[n][i]); return min; }
